## Steps

1. Download all 7 PNG files from GitHub: `https://github.com/ReviewlyAU/reviewly-case-studies/tree/main/thumbnails`

3. For each case study post, go to Edit Post > Featured Image > Set Featured Image
4. Replace the old thumbnail with the new matching file
5. Update/publish each post
