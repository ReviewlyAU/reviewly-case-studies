- **Sub-headline:** White semi-bold (e.g. "Google Visibility Transformed")

- **Footer:** Black bar with sky blue separator line, "Verified Client Outcome" badge left, `reviewly.com.au` right

## Steps

1. Download all 7 PNG files from GitHub: `https://github.com/ReviewlyAU/reviewly-case-studies/tree/main/thumbnails`
2. In WordPress Media Library, upload all 7 files
3. For each case study post, go to Edit Post > Featured Image > Set Featured Image
4. Replace the old thumbnail with the new matching file using the table above to match file to post
5. Update/publish each post
6. Check the live case studies page at `reviewly.com.au/case-studies/` to confirm all 7 thumbnails display correctly
